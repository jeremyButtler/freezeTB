# Use:

Describe the hotkeys for ftbRay.

Main GUI:

- tab: cycle to the next widget or item
- shift and tab: cycle to the last widget or item
- enter: select a widget or item

For entry boxes:

- space: is replaced by an underscore
- home: move to start of entry box
- end: move to end of entry box
- scroll wheel: move cursor up one character
- shift + scroll wheel: move cursor one block
- shift + backspace to delete all text

For list boxes and file browsers:

- j/k, up/down, or scroll wheel : move up or down one item
- J/K, page up/page down, or shift up/ shift down,
  shift scroll wheel: move up or down one page
- h/l, left/right, or control + scroll wheel: move to the
  right or left one character
- H/L, shift left/shift right, or control + shift +
  scroll wheel: move to the right or left one block
- home/end: move to first or last item in the list box
- 0: move to the first column in the list box
- $: move to the last column in the list box
- control left click, control space: add unslected item or
  remove selected item from selection
- control a: add all items (except back one directory)
- shift left click, shift space: add all items between
  the last selected item and this item (does not always
  work).
- enter or click: add item to seletion and remove all
  other items
